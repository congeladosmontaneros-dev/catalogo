⚙ Configuración del pesebre

La clave se guarda solo en este computador (localStorage), nunca en GitHub. Sin clave, el Ángel responde en modo básico con respuestas ya escritas.
Usa una clave dedicada para el pesebre, con un límite de gasto mensual configurado en console.anthropic.com.

Si pones la IP, la página avisa al ESP32 cuando el Ángel escucha o habla (para prender la estrella o las luces). Funciona abriendo el archivo desde el computador, no desde GitHub Pages.

Atajos: Espacio = hablar · C = configuración · F = pantalla completa · R = reiniciar conversación
